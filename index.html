📖 ShiftHub Pro — Guía de Uso

🔐 Daily Report / Dashboard — Solo Team Lead

El PIN de Team Lead es 7890. El Dashboard y el Daily Report son solo para revisar reportes por edificio, por turno, por empleado y para detectar ajustes altos.

🍫 Chocolate Adjustment

Selecciona la línea, el item que está corriendo y el chocolate. Los tanques, enrobers/pipes y bed vienen en 100% por defecto porque casi siempre se reportan completos. Solo modifica ese porcentaje si la línea terminó producción y se hizo retorno o si de verdad no está al 100%.

🥜 Ingredients Adjustment

Escoge la plantilla correcta y escribe la cantidad física. Las libras fijas ya vienen cargadas para evitar errores. La herramienta calcula la diferencia contra sistema.

📦 Pouches Adjustment

La lógica correcta es: primero se hace el scrap que reporta producción. Después el sistema queda en System After Scrap. Luego se calcula el PA necesario para llegar a lo físico. Ejemplo: System 700, Scrap 150 → después del scrap quedan 550. Si físico es 850, el PA debe ser +300.

⏱ Mid Shift / ✅ End Shift

Mid Shift usa solamente completion, sistema, físico y scrap de Mid Shift. End Shift usa solamente los datos de End Shift. En Totals solo se suman los ajustes IMS: Scrap IMS + PA. No se suma completion.

🟢🟡🔴 Estatus

No cambies esta lógica: Acceptable ≤5%, Attention mayor de 5% y menor o igual a 8%, Critical mayor de 8%.

🧾 Pass Off Builder

Pega texto de IMS para detectar Item, LPN y Qty. Recuerda: el LP importante normalmente empieza con R. Agrega ajustes, scrap, movimientos o cycle count y exporta a Word.

📤 Exportar

Usa Word para generar reportes. Antes de limpiar datos, guarda o exporta el reporte.
